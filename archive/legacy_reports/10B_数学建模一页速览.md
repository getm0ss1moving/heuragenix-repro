# 一页速览：EDA 布局布线完整数学建模体系（v1.0）

**主文档：** `10_完整数学建模体系_EDA布局布线与测试_v1.md` ｜ **配套图：** `../_bilingual/diagram/eda_math_model.pdf`（A1，六层模型 × 阶段公式 × 测试协议）  
**定位：** Phase 0 前的数学定稿；只定义模型、测试与判据，不代表已经跑出结果。

## 六层体系

| 层 | 内容 | 核心对象 |
|---|---|---|
| L0 | 设计对象与工艺 | 网表 $\mathcal{D}$、工艺规则 $R$、布局变量 $p$、布线图 $\mathcal{G}_r$、预算 $b$ |
| L1 | 阶段物理模型 | floorplan / GP / legalize / CTS / GRT / DR / signoff 的 $f_g$、$\mathcal{F}_g$、gate |
| L2 | 质量与测试基础 | 指标 $y$、归一化 $\tilde y$、门禁 $G$、效用 $U$（字典序/HVI/CVaR）、配对测试协议 |
| L3 | 决策核心 BMF-CSMDP | option、契约、shield、Bellman、预算/机会约束、在线 Score |
| L4 | 多保真与不确定性 | 偏差 $b_l$、方差 $\sigma_l^2$、LCB/UCB、升保真、OCBA/VOI |
| L5 | 信用、学习与演化 | 反事实 $\delta_i$、Shapley $\phi_i$、势函数 shaping、CA-POR/EDA-CPR、GRPO、双层演化 |
| L6 | 测试与统计协议 | T0–T8 测试层、分层 bootstrap、LCB、失败率 UCB、复现记录 |

## 八个核心公式

1. **HPWL：** $\sum_n[\max x-\min x+\max y-\min y]$
2. **密度溢出：** $\sum_b\max(0,D_b-C_b)/\sum_b C_b$
3. **全局布线 MCF：** 流守恒 + $\sum_n f_{n,e}\le c_e$ + $\min\sum_e\ell_e d_e+\lambda\sum_e o_e$
4. **option Bellman：** $Q(s,\omega)=\mathbb{E}[r+\gamma^{\rho}V(s')]$，$V(s)=\max_{\Omega_{\text{adm}}}Q$
5. **约束目标：** $\max\mathbb{E}[\sum\gamma^{\rho}r]$ s.t. $\Pr(G_3=0)\le\delta_{\text{fail}}$，$\sum\rho\le B$
6. **在线分数：** $\mathrm{Score}=\mathrm{LCB}(\Delta U)-\lambda_c c/b-\lambda_r\mathrm{UCB}(P_{\text{fail}})$
7. **多保真 LCB：** $\mathrm{LCB}_l=\widehat{\Delta U}_l-\beta_l-z\hat\sigma_l/\sqrt{n_l}$
8. **选择器奖励：** CA-POR（单位成本 LCB 排名 + 统计阈值分段偏好）+ EDA-CPR（类别/序数/gate/cost 状态感知）

## 可声明的性质与边界

| 能声明 | 条件 | 不能声明 |
|---|---|---|
| shield 安全性 | 契约/checker 正确、回滚字节级一致 | 每个候选都更好 |
| 点态不劣化 | 候选不过门/不优于 baseline 就回退 | 未见设计族也提升 |
| 统计提升 | 留出 family + 配对 A/B + $\mathrm{LCB}(\Delta)>0$ | 全局最优 |
| 风险有界 | 失败率 $\mathrm{UCB}<\epsilon$ + CVaR 约束 | 绝对零 DRC/LVS 失败 |
| 可复现 | 版本/seed/输入冻结 + 容差内重复 | 模型不漂移 |

## Phase 0 测试清单（进入 Phase 1 的门槛）

P0-1 文档—实现一致 ｜ P0-2 harness 可复现 ｜ P0-3 shield 注入测试 ｜ P0-4 gate 正确性 ｜ P0-5 代理校准 ｜ P0-6 配对估计器（含合成效应与 type-I 控制）｜ P0-7 selector sanity（random/oracle）｜ P0-8 演化门控 ｜ P0-9 预算核算 ｜ P0-10 可追溯性 ｜ P0-11 skill 效力 pilot（6 个 L1 skill × 10–20 checkpoint × 3 seeds）

**Phase 0 退出：** P0-1 到 P0-11 全通过；若 P0-11 无正效应，先修 skill/代理，不进入演化。

## 种子启发式怎么找（主文档 §11）

把 seed 视为**初始契约 option 集合** $\mathcal{L}_0$，目标是最大化后期演化收益，而非当前最强。选种目标：
$$
\max_{\mathcal{L}_0\subset\Omega_0,|\mathcal{L}_0|\le K}\mathbb{E}[\mathcal{J}_{\text{outer}}(\mathcal{M}_{\text{LLM}}^{(E)}(\mathcal{L}_0))]\quad\text{s.t. 安全/覆盖/预算}
$$
代理评分 = 单位成本 LCB 效用 + 状态覆盖 + 可演化性，组合目标再加行为多样性；六类来源：工具原生、经典算法封装、文献/竞赛、经验库挖种、失败驱动修复、LLM 生成（最后做，必须过 verifier）。流程：候选池 → 契约化+F0 → F1 多保真筛选 → 状态簇覆盖/多样性 → F2 配对 pilot+F3 审计 → 组库冻结 $\mathcal{L}_0$。

# 一页报告：HeurAgenix → EDA 布局布线的新流程与数学建模（HA-PR v1.0）

**日期：** 2026-09-21 ｜ **依据：** arXiv:2506.15196v2 + `01` 精读 + `04–08` 机制设计 ｜ **定位：** 流程与数学建模创新，不做新模型训练主贡献。

## 1. 核心结论

HeurAgenix 的"演化 + 在线选择"双层结构可以保留，但它的四个隐含假设——状态廉价、动作短、转移确定廉价、正确性免费——在 EDA 布局布线中都失效。HA-PR 用四段流程和 **BMF-CSMDP** 数学建模逐项替换：

| HeurAgenix 假设 | EDA 现实 | HA-PR 改造 |
|---|---|---|
| 状态低维、便宜 | DEF/ODB/时序/拥塞高维异构 | checkpoint + 双表示（LLM state card + 代理图特征） |
| 动作短、固定 $M=5$ | 工具调用分钟~小时，停止条件因状态而异 | 契约化 option $\omega=(k,\theta,\tau)$ |
| 转移确定、单步 | 工具/seed 有噪声，时长成本随机 | shielded 半 MDP，$\gamma^{\rho}$ |
| 终点代价一次可得 | signoff 昂贵，代理会 reward hacking | 多保真 LCB + 自适应升保真 |
| 正确性天然保证 | 重叠/连通/DRC/LVS/STA 是硬门槛 | 契约 + L0–L3 验证栈 + chance constraint + 回滚 |

## 2. 新流程清单（四段式）

1. **Phase O 离线准备（9 步）**：冻结工具链/设计 → baseline + 每阶段 checkpoint → 指标/gate/归一化 → state card + 图特征 → skill schema + 首批 L1 skill → L0–L3 验证栈 + shield → 多保真评估器 + surrogate 校准 → Experience Bank + meta 日志 → 按 design family 切分。
2. **Phase R 在线执行（9 步）**：状态卡 → selector 提 Top-$K$ 候选 → 硬过滤 → 多保真 LCB/UCB 估值 → 选 $\arg\max \mathrm{Score}$ → 快照 + sandbox 执行 → gate 检查（失败回滚/fallback）→ 更新 Bank/surrogate/预算 → 终止或 signoff。
3. **Phase E 门控演化（8 步）**：正/负轨迹 → 对齐差异决策 → 反事实 $\delta_i$/Shapley $\phi_i$ 定位关键决策 → 演化 prompt → LLM 提 L1/L2/L3 变异 → 单测/canary → 多保真 + 跨族评估 → `LCB(ΔU)>0 且 UCB(违规)<ε` 才晋升。
4. **Phase D 部署/蒸馏（可选）**：蒸馏 selector（CA-POR + EDA-CPR）→ shadow/canary → 版本化上线 → 监控与回滚。

**阶段图：** `floorplan → global placement → legalization → CTS → global route → detailed route → signoff`，允许跳跃、回退、迭代；每阶段有明确指标、硬 gate 和 5–8 个候选 skill。

## 3. 新数学建模：BMF-CSMDP

**状态/动作：** $s=(g,d,x_g,m_g,b,h)$，$\omega=(k,\theta,\tau)$，契约 $C_k=(\mathrm{Pre},\mathrm{Post},\mathrm{Inv},\mathrm{Fallback},\mathrm{Cost})$。

**核心公式 1（option Bellman）：**
$$
Q(s,\omega)=\mathbb{E}[\,r(s,\omega,s')+\gamma^{\rho(\omega)}V(s')\,],
\qquad V(s)=\max_{\omega\in\Omega_{\mathrm{adm}}(s)}Q(s,\omega)
$$

**核心公式 2（预算约束多目标）：**
$$
\max_{\pi}\ \mathbb{E}\Big[\sum_j\gamma^{\rho_j}\Delta U(s_j,s_{j+1})\Big]
\quad \text{s.t.}\quad
\Pr(G_3=0)\le\delta_{\text{fail}},\quad \sum_j\rho_j\le B_{\mathrm{time}},\quad \sum_j c^{\mathrm{api}}_j\le B_{\mathrm{api}}
$$

**核心公式 3（在线选择分数）：**
$$
\mathrm{Score}(s,\omega)=\mathrm{LCB}_{1-\alpha}[\Delta U]-\lambda_c\,\hat c/b-\lambda_r\,\mathrm{UCB}_{1-\alpha}[P_{\mathrm{fail}}]
$$

**核心公式 4（跨阶段信用）：**
$$
\Phi(s)=-\big(\lambda_1\widehat{OF}_{\mathrm{route}}+\lambda_2\widehat{TNS}_{\mathrm{post}}+\lambda_3\widehat{DRC}\big),\qquad
r_{\mathrm{train}}=r_{\mathrm{PPA}}+\gamma^{\rho}\Phi(s')-\Phi(s)
$$

**选择器学习：** CA-POR 按"单位成本 LCB 效用 − 风险"排名，正/负集由统计置信区间决定；EDA-CPR 在类别/二值特征外增加序数严重度 $|z_j-\hat z_j|$、gate 预测和成本校准；用 GRPO 训练。

## 4. 创新点一句话清单

1. **流程创新：** 阶段图 + 契约化 option + 三库（skill / experience / verifier）双循环。
2. **数学创新：** 把 HeurAgenix 的单层确定 MDP 扩展为"预算约束 + 多保真 + 机会约束"的半 MDP（BMF-CSMDP）。
3. **信用分配创新：** checkpoint 级反事实重放 + Shapley 近似 + 下游感知势函数 shaping。
4. **选择器创新：** CA-POR（成本感知、统计阈值）与 EDA-CPR（序数状态、gate、成本）。
5. **安全创新：** 正确性由契约、L0–L3 验证栈、回滚与机会约束保证，而不是靠 LLM。

## 5. 实验计划与验收（摘要）

- **H1** shield/option 流程 → gate 通过率、无效评估次数；
- **H2** 多保真 LCB → time-to-target、同预算候选数；
- **H3** 跨阶段 shaping → post-route overflow、WNS/TNS、DRC；
- **H4** CA-POR + EDA-CPR vs vanilla GRPO/原始 POR → selector regret、最终 PPA；
- **H5** 反事实信用 + 门控演化 → 达到目标质量的评估次数、晋升率。
- **基线与协议：** baseline flow / 随机 / 静态最佳 / BO-bandit / 原始 TTS；按 design family 切分，≥3 seeds，配对 A/B + 分层 bootstrap + LCB。
- **Phase 0 MVP（1–2 周）：** OpenLane1 + sky130A，`spm`/`gcd`，6 个 L1 skill，10–20 checkpoint × 3 seeds，dsv4-flash selector + random/oracle 三档。
